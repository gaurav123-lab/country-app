# 🌍 Country Explorer App

🚀 A fast and modern web application built using **React + Vite** that allows users to explore detailed information about countries around the world.

This project focuses on performance, clean UI, and seamless user experience.

---

## 🔗 Live Demo

👉 https://deluxe-moxie-5deacf.netlify.app/

---

## ✨ Key Highlights

* ⚡ Built with **Vite** for lightning-fast performance
* 🌍 Real-time country data using API
* 🎯 Clean and responsive UI
* 🔍 Instant search functionality
* 📊 Dynamic data rendering

---

## 📌 Features

* 🌎 View all countries
* 🔍 Search countries by name
* 🎯 Filter countries by region
* 📊 Detailed information (population, capital, region, etc.)
* ⚡ Smooth and fast user experience

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** CSS
* **Routing:** React Router
* **API:** REST Countries API
* **Deployment:** Netlify

---


## ⚙️ Installation & Setup

```cmd
git clone https://github.com/gaurav123-lab/country-app.git
cd country-app
npm install
npm run dev
```

---

## 📦 Build for Production

```cmd
npm run build
```
